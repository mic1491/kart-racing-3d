# 🏎️ 跑跑積木卡丁車 3D (KartRider LEGO 3D)

使用 **單一 HTML 檔 + Three.js 3D** 打造的樂高風格跑跑卡丁車賽車遊戲，無需安裝或建置，直接雙擊 `index.html` 或部署到 GitHub Pages 即可開玩！

## ✨ 遊戲特色
- **雙主角積木賽車**：`#27 閃電金星`（黃藍經典款）與 `#4 霓虹暗影`（黑青粉雙噴款），搭配 4 人同場 AI 競速。
- **4 張 3D 賽道場景**：
  - 🌲 積木城鎮
  - 🏜️ 黃金沙漠
  - 🌃 霓虹夜市
  - ❄️ 極地冰原
- **雙模式玩法**：
  - **🎁 道具模式**：賽道上配置 `?` 道具箱，含 🚀 追蹤飛彈、🍌 香蕉皮、💧 水炸彈、🛡️ 天使護盾、⚡ 黃金氮氣。
  - **⚡ 競速模式**：甩尾集氣累積 N2O 氮氣瓶 + 放開甩尾觸發小噴加速。
- **跨裝置操控**：支援鍵盤與行動裝置虛擬觸控按鍵（點右上角 `📱` 切換），並內建 Web Audio 程序化引擎／甩尾／道具音效。

## 🎮 操作說明
| 按鍵 | 功能 |
| :--- | :--- |
| `W` / `↑` | 加速 |
| `S` / `↓` | 煞車 / 倒車 |
| `A` `D` / `←` `→` | 左右轉向 |
| `Shift` | 甩尾飄移（累積氮氣、放開觸發小噴） |
| `Space` / `Ctrl` | 施放道具 / 釋放 N2O 氮氣 |
| `R` | 重新開始比賽 |

## 🚀 開始遊玩
直接用現代瀏覽器開啟 [index.html](index.html) 即可遊玩（需連網載入 Three.js CDN）。
