# 🏎️ 跑跑積木卡丁車 3D (KartRider LEGO 3D)

使用 **單一 HTML 檔 + Three.js 3D** 打造的樂高風格卡丁車賽車遊戲，無需安裝，直接雙擊 `index.html` 或部署到 GitHub Pages / Netlify 即可開玩！

`index.html` 已經把 3D 引擎、音樂、音效全部包在裡面（約 1 MB），**不用連網也能玩**（只有「4人區網」連線對戰需要網路）。

## ✨ 遊戲特色
- **12 張 3D 賽道**：積木城鎮、黃金沙漠、霓虹夜市、極地冰原、海灘、櫻花、火山、彩虹太空、雲端天國、恐龍侏羅紀、🍭 **糖果王國**（新：穿越巨型旋轉甜甜圈、棒棒糖森林、生日蛋糕山）、🏝️ **海島大冒險**（新：跳島飛越缺口、跨海懸索大橋、海底玻璃隧道看鯨魚和魚群，沒飛過去會掉海）
- **14 台車 + 15 位車手**：新增 🐻 台灣黑熊、⚾ 棒球少年、🧋 珍奶店長、🐱 喵喵車手、🏴‍☠️ 海盜船長、👑 糖果公主、🤖 機器人 K9、🦖 小暴龍、🧙 星空魔法師；新車 🧋 **珍珠奶茶號**（杯底珍珠會隨車速與甩尾滾動）；電腦對手每場隨機換車手
- **🗣️ 角色語音**：每位車手有自己的聲音和台詞，起跑、超車、被超車、被打中、命中對手、最後一圈、掉海、衝線都會喊一句（用裝置內建中文語音，不需音檔；可在大廳關閉）
- **4 種模式**：道具賽、競速賽、氣球大亂鬥、冠軍錦標賽
- **20+ 種道具**，含 🐉 **神龍附身**（新：落後專用，自動駕駛 3.6 秒＋無敵）
- **最後一名逆轉**：落後第一名超過 1/4 圈會啟動「🔥 逆轉氣場」（加速＋藍色光環），而且道具箱更容易抽到神龍附身
- **大場面運鏡**：被擊中、命中對手、超車、飛躍跳台時，鏡頭特寫＋慢動作＋電影黑邊＋大字
- **被擊中提示**：畫面中央大字說明發生什麼事（例如「墨汁噴臉！」「左右顛倒！」），加上倒數圓環
- **燒胎**：停著時油門＋煞車一起按 → 原地燒胎冒煙、留下黑色胎痕，放開煞車彈射起步（燒越久衝越猛）
- **輪胎尖叫聲＋胎痕**：甩尾、急彎、打滑時會有輪胎摩擦聲和黑色胎痕
- **退賽倒數**：有人先衝線後，還沒完賽的玩家只剩 10 秒
- **華麗特效**：光暈（火焰、霓虹、火花、太陽會發光）、噴射彩色光尾、高速光線；「畫質」可選自動／華麗／中／省電，自動模式卡頓時會自己降畫質保持流暢
- **同機雙人分割畫面**、**4 人連線房間**（PeerJS）

## 🎲 大亨賽車模式（tycoon 分支・開發中）
大廳「玩法模式」選 **🎲 大亨賽車**，就是大富翁 × 卡丁車：
- **棋盤**：20 格，其中 12 格是賽道地產，另有起點（經過 +200）、機會 ×4、維修站（休息一回合）、神龍門（隨機傳送）、加油站（+150）
- **擲骰子**前進；擲出一樣的點數可以再擲一次
- **買地、蓋房**：停在沒人買的賽道可以買；停在自己的地可以升級（最多 Lv.3，過路費越來越貴）
- **停在別人的地**：付過路費，或發起 **🏁 挑戰賽**，在那張賽道跟地主單挑 1 圈。贏了免付還反收一半；輸了付雙倍。地主等級越高，起跑噴射越久
- **機會卡**：神龍附身、黃金氮氣、香蕉皮、磁鐵、天雷、加速帶、墨魚、金幣雨、免費改裝、超速罰單
- **結束**：10 回合後（或只剩一人沒破產），**總資產**（金幣＋地價＋房子）最高的人獲勝
- 單人：你 + 3 個電腦；同機雙人：2 人輪流 + 2 個電腦（兩個真人單挑時自動分割畫面）
- 鍵盤 Space／Enter、手把 A、或直接點按鈕操作


| 設定 | 說明 |
| :--- | :--- |
| 🔠 字體大小 | 標準 / 大（預設）/ 特大，會依螢幕自動再縮放，大人也看得清楚 |
| 電腦對手難度 | 🐣 簡單 / 🏎️ 普通 / 🔥 困難 |
| 畫質 | ✨ 自動（預設，先用華麗、卡就自動降）／💎 華麗／🙂 中／🔋 省電 |
| 角色語音 | 🗣️ 開／🤐 關 |
| 新手轉向輔助 | 開：沒按方向時車頭自動對準賽道、快撞牆時輕推回來；關：完全手動 |

## 🎮 操作說明
| 鍵盤 | 功能 |
| :--- | :--- |
| `W` / `↑` | 加速 |
| `S` / `↓` | 煞車 / 倒車 |
| `A` `D` / `←` `→` | 左右轉向 |
| `Shift` | 甩尾（放開觸發小噴）／空中 360° 特技 |
| `Space` / `Ctrl` | 施放道具 / 釋放 N2O 氮氣 |
| `H` | 喇叭表情 |
| `P` / `Esc` | 暫停 |
| `R` | 重新開始 |

雙人同機：P1 用 `WASD + 左Shift`，P2 用 `方向鍵 + 右Shift`。

### 🕹️ 手把（Xbox / PlayStation / USB 搖桿）
插上（或藍牙配對）後**先按任一鍵**喚醒，大廳會顯示「已連接手把」。最多 2 支，第 1 支是 P1、第 2 支是 P2。

| Xbox | PlayStation | 功能 |
| :--- | :--- | :--- |
| 左搖桿 / 十字鍵 | 左搖桿 / 十字鍵 | 轉向（搖桿可微調） |
| A / RT | ✕ / R2 | 加速（大廳按 A / ✕ = 開始比賽、結算畫面 = 再玩一次） |
| B / LT | ○ / L2 | 煞車 |
| X / RB | □ / R1 | 甩尾 |
| Y / LB | △ / L1 | 道具 / N2O |
| View | Share / Create | 喇叭表情 |
| Menu | Options | 暫停 / 繼續 |

**選單也能用手把操作**：十字鍵／左搖桿移動（黃框顯示目前位置）、A 選擇、B 返回、LB / RB 切換分頁、Start / Menu 直接開始比賽。

USB 街機雙人搖桿（零延遲編碼板，DragonRise 等）也支援，搖桿方向會自動判讀。

### 📱 手機
點右上角 `📱` 切換觸控按鍵（手機會自動開啟）。油門自動踩；左手按住大轉向板左右滑（越往外轉越多），右手按甩尾、道具。建議橫放。

## 🔊 音效
全部音效和音樂都是程式即時合成，已經包在 `index.html` 裡，不需要任何音檔：
- 3 首背景音樂（陽光、夜晚合成器、快節奏搖滾），依賽道自動切換，最後一圈加速
- 引擎換檔聲、輪胎尖叫聲、燒胎、噴射「咻」聲、撞擊低音、道具轉盤、倒數 3‧2‧1‧GO、過圈與冠軍音樂

### 想換成真實錄音（選用）
1. 在專案資料夾建一個 `sounds` 資料夾，放入 `.mp3`，檔名照下表（只放想換的就好）
2. 執行 `node build.mjs`，音檔會被直接嵌進 `index.html`，**依然是單一檔案**

| 檔名 | 用途 |
| :--- | :--- |
| `engine.mp3` | 引擎循環聲（會依車速自動變調） |
| `screech.mp3` | 輪胎摩擦循環聲 |
| `boost.mp3` / `hit.mp3` / `item.mp3` / `coin.mp3` | 加速／被擊中／拿到道具／金幣 |
| `countdown.mp3` / `go.mp3` / `lap.mp3` / `win.mp3` | 倒數嗶聲／GO／過圈／前三名 |
| `bgm.mp3` 或 `bgm_sunny.mp3`、`bgm_night.mp3`、`bgm_action.mp3` | 背景音樂（依賽道風格） |

免費可商用的音效：[Kenney](https://kenney.nl/assets/category:Audio)（CC0）、[OpenGameArt](https://opengameart.org)（請選 CC0 授權）。

## 🛠️ 開發
程式碼在 `src/`，改完後執行一次打包，產生可直接開的 `index.html`：

```bash
node build.mjs          # 完整單檔（含 3D 引擎，離線可玩，約 1 MB）
node build.mjs --cdn    # 輕量版（3D 引擎從網路載入，約 400 KB，要連網）
```

`vendor/three.module.min.js` 是 Three.js r160（MIT 授權，授權文字在 `vendor/three-LICENSE.txt`）。

網址加上 `?debug` 可在瀏覽器主控台用 `__kart` 查看比賽狀態。
